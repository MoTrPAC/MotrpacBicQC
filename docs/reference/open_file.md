# open files

open files and check that they are right

## Usage

``` r
open_file(input_results_folder, filepattern, verbose = TRUE)
```

## Arguments

- input_results_folder:

  (char) input path folder

- filepattern:

  (char) regular expression to find a file in the file system provided

- verbose:

  (logical) `TRUE` (default) shows messages

## Value

(list) list with data frame and flag about the status
