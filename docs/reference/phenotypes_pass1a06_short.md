# Motrpac Phenotypes PASS1A 6 Months

Motrpac Phenotypes PASS1A 6 Months

## Usage

``` r
phenotypes_pass1a06_short
```

## Format

A data frame with 8616 rows and 6 columns:

- tissue_code:

  MoTrPAC Tissue code

- vial_label:

  Vial label id (only available for MoTrPAC Samples)

- tissue_name:

  Tissue name

- group_time_point:

  Group time point

- sex:

  Animal sex

- site_code:

  cas
