# Metadata Metabolites test dataset for NAMED metabolites

Metadata Metabolites test dataset for NAMED metabolites

## Usage

``` r
metadata_metabolites_named
```

## Format

A data frame with 53 rows and 6 columns:

- metabolite_name:

  metabolite names

- refmet_name:

  RefMet id (metabolomics workbench)

- mz:

  mass over charge

- rt:

  retention time

- formula:

  chemical formula

- neutral_mass:

  neutral mass
