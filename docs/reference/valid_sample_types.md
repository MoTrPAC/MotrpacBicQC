# Valid sample types for QC validation

A character vector of all accepted values for the `sample_type` column
in metadata_sample files. Used by `check_metadata_samples`,
`check_metadata_samples_lab`, and `check_metadata_samples_olink`.

## Usage

``` r
valid_sample_types
```

## Format

A character vector with 13 elements

## Examples

``` r
if (FALSE) { # \dontrun{
 valid_sample_types
} # }
```
